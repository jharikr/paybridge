# paybridge

Paybridge is a project under Transact.

This initial commit contains repository documentation and instructions for coding assistants. Application setup will follow the owner's next command. No runtime, framework, or build commands have been chosen yet.

## Work locally

The local repository is `~/Developer/transact/paybridge`.

```sh
cd ~/Developer/transact/paybridge
```

## Coding assistants

Start Codex or Claude Code from the repository root:

```sh
codex
# Or
claude
```

`AGENTS.md` contains the shared project instructions. `CLAUDE.md` imports those instructions for Claude Code. The Unslop writing skill lives in `.agents/skills/unslop/SKILL.md`.

These files configure repository instructions. Sign in to each assistant with your own account when prompted.
