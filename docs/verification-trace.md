## Scope of the evidence

Tests use the locked stack, real local HTTP, trusted local commands, actual Node processes and independent synthetic SQLite files. Controlled clocks and IPC gates exist only at the approved test seams. The provider overlap cases retain a real request below its configured HTTP deadline while advancing the scheduling clock to permit reclamation. They do not invent a response after hard-aborting fetch. A separate held-acceptance case shows a timed-out request executing later while Paybridge remains UNKNOWN.

Signed delivery is at least once. A 204 establishes a durable receipt, a 202 or 303 establishes command acceptance, and local PAID requires guarded application of a verified newer success snapshot. The retained demo observes local orders before merchant lookup/return can independently apply that snapshot. Manual evidence remains an operator trust boundary; an exported JSON object is not live-provider attestation.

Mock account-and-transaction finality and deduplication are explicit simulation assumptions. No test establishes live NCBA/4Cs retention, concurrent failover, live tokenization, real-card recovery, settlement finality or production compliance. The demo deliberately retains an inconclusive UNKNOWN. These limits are expected results, not missing assertions to be hidden by forced terminal status.
